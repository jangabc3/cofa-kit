# 다음에 할 일 안내

사용자는 스킬 이름과 순서를 기억하지 않아도 된다. 이 스킬이 지금 단계를 판단해 다음 한 걸음만 알려 준다.

## 1. 시간 확인
- `.cofa/START` 파일이 없으면 사용자에게 "과제를 몇 시에 시작했나요? 제한 시간은 몇 분인가요?"라고 묻고, 답을 `.cofa/START`에 `시작=HH:MM 제한=180` 형식으로 적는다.
- 있으면 `date +%H:%M`으로 현재 시각을 보고 경과 시간과 남은 시간을 계산한다.

## 2. 단계 판단 (위에서부터 처음 해당하는 것)
| 상태 | 단계 | 다음에 쓸 것 |
|---|---|---|
| 남은 시간 15분 이하 | 마무리 | `HANDOFF.md`가 없으면 `$cofa-handoff` 제출용, 있으면 "지금 제출하세요" |
| 남은 시간 25분 이하 | 정리 | `$cofa-verify` → `$cofa-handoff` 제출용 → `$cofa-explain` 중 아직 안 한 것 |
| `INTERVIEW.md` 없음 | 시작 | `$cofa-interview` 질문 뽑기 |
| 기록된 담당자 답이 5개 미만 | 인터뷰 | 담당자에게 다음 질문 하기 → 답을 `$cofa-interview`로 기록 |
| `AGREEMENT.md` 없음 | 합의 | `$cofa-agreement` |
| `PLAN.md` 없음 | 계획 | `$cofa-plan` |
| 핵심 방식을 사용자가 아직 안 고름 (`DECISIONS.md`에 방식 결정 없음) | 방식 고르기 | 🙋 직접 할 것: PLAN.md의 방식 표를 보고 하나를 골라 이유와 함께 말하기 |
| `PLAN.md`에 안 끝난 작업 있음 | 구현 | "PLAN.md 작업 N번만 해 줘. 확인하고 커밋하고 멈춰." |
| 모든 작업 끝남, `DECISIONS.md`에 `[화면]` 항목 없음 | 화면 다듬기 | `$cofa-ux 사용자 입장에서 화면을 다듬어 줘. 새 기능은 넣지 마.` |
| 모든 작업 끝남, `VERIFICATION.md` 없음 | 검증 | `$cofa-verify` |
| 그 외 | 마무리 | `$cofa-handoff` 제출용 → `$cofa-explain` |

추가 확인
- 이 세션에서 대화가 아주 길어졌거나 시작한 지 90분이 넘었는데 세션을 바꾼 적이 없으면, 큰 작업이 끝난 시점에 `$cofa-handoff` 세션 교체용을 권한다.
- 최근에 무언가를 정했는데 `DECISIONS.md`에 없으면 `$cofa-decisions`를 먼저 권한다.

## 3. 답하는 모양 (이 형식 그대로, 5줄 이내)
```
⏱ 경과 75분 / 남은 105분
📍 지금 단계: 구현 (PLAN.md 작업 2/4)
👉 다음: 작업 2번을 시킵니다.
⌨️ 입력: PLAN.md 작업 2번만 해 줘. 확인하고 커밋하고 멈춰.
🙋 직접 할 것: 작업 1번 화면을 Browser에서 눌러 보기
```
이 형식에 이미 다음 할 일이 들어 있으므로 `👉 다음:` 줄을 따로 또 붙이지 않는다.
인터뷰 단계라면 "⌨️ 입력" 대신 "💬 담당자에게:"로 메신저에 보낼 질문 하나를 쓴다.
