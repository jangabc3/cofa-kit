# 인수인계

## A. 제출용 HANDOFF.md
```
# 인수인계

## 무엇을 만들었나 (담당자의 말로 3줄)
## 실행과 사용 방법
- 실행: (명령 한 줄, 포트)
- 쓰는 순서: 1. … 2. … 3. …
## 합의한 것 중 된 것 / 안 된 것
| 항목 | 상태 | 비고 |
## 만들지 않은 것과 이유
## 알려진 약점과 위험
- (어디서, 어떤 입력에서 틀릴 수 있나 → 그때 무슨 일이 생기나)
## 다음에 할 일 (우선순위 순)
## 담당자에게 남은 질문
```
`AGREEMENT.md`, `DECISIONS.md`, `VERIFICATION.md`, `git log --oneline`을 근거로 쓴다. 근거 없는 내용은 쓰지 않는다.

## B. 세션 교체용 인수인계
대화가 길어져 느려지거나 같은 설명을 반복하게 되면, `.handoff/SESSION.md`에 아래만 남기고 사용자에게 새 세션을 시작하라고 알린다. 남은 시간은 `.cofa/START`와 `date +%H:%M`으로 계산하고, 파일이 없으면 사용자에게 묻는다.
```
- 목표와 남은 시간:
- 지금 단계 (PLAN.md 작업 번호):
- 방금 한 것 / 막힌 것:
- 다음에 할 한 가지:
- 꼭 읽을 파일:
```
새 세션 첫 요청은 "`.handoff/SESSION.md`부터 읽고 이어서 해 줘"다.
