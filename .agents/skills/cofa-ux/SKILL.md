# 화면 다듬기 (업무 도구용)

이 화면은 광고 페이지가 아니라 **업무 도구**다. 멋보다 "처음 보는 사람이 5초 안에 무엇을 할지 아는가"가 먼저다. 화려함보다 한눈에 훑어보기, 일관성, 실제 사용 장면이 우선이다.

## 0. 먼저 읽기
`AGREEMENT.md`에서 화면에 영향을 주는 조건을 찾는다: 누가, 어디서, 무엇(기기)으로, 얼마 동안 보는지. 예: 장갑 → 버튼 48px 이상 / 5분 안에 봄 → 한 화면 요약 / 신입 → 쉬운 말.
`PLAN.md`의 "화면 흐름"이 있으면 그대로 따른다.

역할이 여럿이면 (예: 운영자 / 이용자)
- 지금 어느 역할 화면인지 맨 위에 늘 보이게 한다 (예: "운영자 화면").
- 역할마다 주요 버튼은 하나. 이용자 화면에는 바꾸는 버튼(추가·수정·삭제)을 보이지 않게 한다.
- 운영자 화면의 바꾸는 동작은 결과를 바로 보여 주고, 지우기처럼 되돌리기 어려운 동작은 한 번 더 묻는다.
- 두 화면이 같은 데이터를 쓰면 이름과 표시 방식을 똑같이 맞춘다.

## 1. 꼭 고칠 네 가지
| 문제 | 규칙 |
|---|---|
| 글자가 작다 | 본문 16px 이상(태블릿·현장은 18px), 제목 28 / 소제목 20 / 본문 16~18 / 보조 14. 줄 간격 1.5, 한 줄 80자 이하 |
| 뭘 눌러야 할지 모른다 | 첫 화면 위쪽에 사용 순서 "① ___ → ② ___ → ③ ___". 화면마다 **주요 버튼은 하나만** 크고 진하게, 나머지는 옅게. 버튼 글자는 동사로("파일 올리기", "초안 만들기") |
| 투박하다 | 스타일 하나로 통일: 배경 밝은 회색, 내용은 흰 카드(둥근 모서리 8~12px, 옅은 그림자), 여백 8의 배수(8/16/24/32). 색은 기본 1개 + 의미 색(위험 빨강, 주의 주황, 정상 초록)만 |
| 결과가 보기 어렵다 | 가장 중요한 결과를 맨 위에 크게(숫자·한 줄 요약). 목록은 표보다 카드, 카드마다 상태 표시(색 + 글자, 색만 쓰지 않기). 위험한 항목이 먼저 |

## 2. 상태 안내 (빠지기 쉬움)
- 처음(빈 화면): 무엇을 하면 되는지 한 줄 + 주요 버튼
- 로딩: 버튼 비활성 + "만드는 중… (10초쯤 걸려요)"
- 입력 누락: 그 칸 바로 아래 빨간 글씨로 무엇이 빠졌는지
- 오류·AI 실패: 무슨 일인지 쉬운 말 + 다음 행동("다시 시도" 버튼 또는 대체 결과)
- 성공: 무엇이 됐는지 짧게("확인 기록을 남겼어요 · 06:03 김○○")

## 3. 만드는 방식
- 기존 HTML/CSS만 고친다. 프레임워크·외부 글꼴·외부 CDN을 새로 넣지 않는다(시험 환경에서 막힐 수 있다). 글꼴은 `system-ui, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`.
- 색·크기·여백은 CSS 변수(`:root`)로 한곳에 모은다.
- 한 열 배치, 최대 너비 960px, 태블릿·좁은 화면에서도 가로 스크롤이 없게.
- 쉬운 한국어. 개발 용어(JSON, API, null 등)는 화면에 보이지 않게.
- 접근성: 글자와 배경 대비 충분히, 입력칸에 이름표, 키보드 포커스가 보이게.
- AI가 만든 티 피하기: 화려한 그라데이션 배경, 장식용 이모지 남발, 모든 카드에 움직임, 의미 없는 번호(01/02), 크림색 배경 + 주황 포인트, 검정 배경 + 형광색.
- 새 기능, 새 화면은 만들지 않는다. 범위 밖이면 제안만 한다.

## 4. 끝나면
1. 바꾼 것을 5줄 이내로 요약한다 (어떤 담당자 조건을 어디에 반영했는지 포함).
2. `DECISIONS.md`에 `[화면]` 항목 하나: 근거 조건 → 화면에서 바꾼 것.
3. 사용자에게 "처음 보는 사람" 점검표를 주고 Browser에서 직접 해 보게 한다.
```
□ 첫 화면에서 5초 안에 무엇을 할지 알 수 있다
□ 눌러야 할 버튼이 하나로 눈에 띈다
□ 글자를 가까이 가지 않고도 읽을 수 있다
□ 가장 중요한 결과가 맨 위에 있다
□ 빈 입력, 로딩, 오류일 때 무엇을 할지 안내가 나온다
□ 담당자가 말한 사용 환경(기기, 장소, 시간)에 맞다
□ (역할이 여럿이면) 각 역할로 들어가 해야 할 일을 끝까지 해 볼 수 있고, 이용자 화면에서 바꾸는 버튼이 보이지 않는다
```
4. 커밋한다. push는 하지 않는다.
