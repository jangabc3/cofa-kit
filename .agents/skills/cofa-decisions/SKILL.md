# 결정 기록

`DECISIONS.md`에 항목을 덧붙인다. 지우지 않고, 바뀌면 새 항목으로 남긴다.

```
## D7. (짧은 제목)
- 근거: (누가 말했는지 정확히: 담당자 Q3 / 내(사용자) 판단 / 자료에서 본 것 / 시간 제약)
- 결정: (무엇을 어떻게 하기로 했나)
- 이유: (왜. 한두 문장)
- 버린 대안: (생각했지만 안 한 것과 이유)
- 코드 위치: (파일:함수, 없으면 생략)
```

`[수정]` 항목 (AI 제안을 거절하거나 고친 경우)은 아래 순서로 쓴다. 나중에 그 과정을 순서대로 되짚어 설명할 수 있게 하기 위해서다.
```
## D8. [수정] (짧은 제목)
- 계기: (무엇을 보고 이상하다고 느꼈나: 화면에서 본 것 / 담당자 말과 다름 / 문서를 읽다가)
- 내 요청: (AI에게 어떻게 검토나 수정을 요청했나, 한 줄)
- AI 제안: (AI가 처음 내놓은 것)
- 받아들인 것 / 바꾼 것 / 뺀 것: (각각, 없으면 생략)
- 근거: (담당자 Q번호 / README / 확인 결과)
- 확인: (고친 뒤 어떻게 확인했나)
```
README가 AI 협업 기록 문서를 요구하면 `[수정]` 항목을 그 문서에도 같은 순서로 옮긴다.

규칙
- 사용자가 AI(Codex)의 제안이나 결과를 거절하거나 고치면 위 `[수정]` 형식으로 남긴다.
- 사용자가 나중에 AI 없이 이 결정을 설명할 수 있도록 쉬운 말로 쓴다.
- 일반 항목은 6줄, `[수정]` 항목은 8줄을 넘기지 않는다.
- 기록한 뒤 사용자에게 "D7을 남겼습니다: (제목)"이라고만 알린다.
